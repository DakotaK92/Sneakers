a# Sneakers | Redux Project

## Description
This is a project to add an item to a cart and remove it using redux, nextjs and tailwind css.

 - [Installation](#installation)
 - [Usage](#usage)

## Installation
Download the code and open your terminal or git bash. Run `npm install` to install the dependencies. Then use `npm run dev` to run the code and go to "http://localhost:3000" to view the website

## Usage
This site is also live and [deployed on Vercel](https://sneakers-sage-chi.vercel.app/).
